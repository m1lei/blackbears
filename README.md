# Blackbears — загрузка аудиозаписей

Учебное приложение на FastAPI: загрузка аудиофайлов (WAV/MP3) с сохранением метаданных в SQLite.

## Требования

- [uv](https://docs.astral.sh/uv/)
- Python 3.12+ (установится автоматически через uv)

## Установка

```bash
uv sync
```

## Запуск

```bash
uv run uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000 — форма загрузки и таблица записей.

## Тесты

```bash
uv run pytest
```

## Конфигурация

Переопределяется переменными окружения или файлом `.env` (см. `.env.example`):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DATABASE_URL` | `sqlite:///data/app.db` | URL подключения к БД |
| `AUDIO_STORAGE_DIR` | `storage/audio` | Каталог хранения аудиофайлов |
| `MAX_FILE_SIZE_BYTES` | `52428800` (50 МиБ) | Максимальный размер файла |
| `ALLOWED_EXTENSIONS` | `.wav,.mp3` | Разрешённые расширения |

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/` | Страница с формой загрузки и списком записей |
| `GET` | `/health` | Проверка живости: `{"status": "ok"}` |
| `GET` | `/recordings` | JSON-массив записей (новые сверху) |
| `POST` | `/recordings` | Загрузка файла (multipart, поле `file`); `201` с объектом записи |

Ошибки: `400` — нет расширения, `413` — превышен лимит размера, `415` — неподдерживаемый формат.
